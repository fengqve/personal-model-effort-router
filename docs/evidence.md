# Evidence format

The canonical runtime format is maintained inside the distributable Skill: [evidence and execution](../skills/route-model-effort/references/evidence-and-execution.md).

The Agent prepares these records from permitted local material. User priorities can set `objective` to cost, latency or quality; availability is represented by `allowed_candidates`. Official recommendations and user defaults are priors, not observed runs. Missing effective-configuration evidence is recorded as unconfirmed and excluded from performance comparison.

The examples directory contains synthetic fixtures only. Use the helper's `demo` for fresh synthetic timestamps. Neither examples nor mock tests are actual model evaluation results.
